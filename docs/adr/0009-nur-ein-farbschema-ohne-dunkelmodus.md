# Nur ein Farbschema, kein Dunkelmodus

Die App verwendet **immer** das Pergament-Schema — unabhängig von der Systemeinstellung und
ohne dynamische Material-You-Farben. Der Pergament-/Piraten-Look ist inhärent hell; eine
dunkle Variante wäre entweder ein anderes Thema oder ein schlechter Kompromiss. Dynamische
Systemfarben würden die handgemalten Grafiken zusätzlich brechen.

## Consequences

Wer den fehlenden Dunkelmodus für ein Versehen hält, wird ihn ergänzen wollen. Das ist eine
Design-Entscheidung, keine Lücke. Ein manueller Umschalter steht als Idee in `ROADMAP.md` —
er bräuchte dann ein zweites, eigenständig gestaltetes Thema samt passender Grafiken, nicht
nur invertierte Farben.
